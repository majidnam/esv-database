# esv-database
This is a PostgreSQL database project, developed around the idea of helping to facilitate fictional employer-supported volunteering (ESV) schemes. This project was created for learning and portfolio purposes.

## Background
In ESV, also known as corporate volunteering, employers support their own employees to take part in volunteering activities with external organisations and charities.
This database project has been designed to store and organise data which could be used to facilitate collaboration between employers and volunteer involving organisations for fictional ESV schemes. For example:

* The project could be used by employers to find volunteering projects based on criteria such as date, location, and types of work involved.
* It could also be used by volunteer involving organisations to find relevant employers who may be interested in taking part in ESV.
* The database also stores feedback about ESV activities from both employers and volunteer involving organisations.

Note that in several places throughout the project, the terms 'charity' and 'charities' are currently being used to refer to volunteer involving organisations.


*Important note*: The data used to seed the tables (found in `dummy_data.sql`) are dummy data. The employers, charities/ volunteer involving organisations, volunteering roles, feedback reviews, and all references in the dummy data are fictional. This database project was created for portfolio purposes, and in order to be used to learn more about and practise the use of SQL and database development.
